はじめに

ZIPの展開から、Codexの活動がViewerに表示されるまでを順に説明します。

このページの内容
  • 準備とZIP展開
  • Windowsの警告
  • 初回起動
  • Viewerを開く
  • 更新・削除

1. 準備とZIP展開

ZIP内から直接EXEを起動せず、まずすべてのファイルをフォルダへ展開してください。たとえばC:\AI-Office-Viewerや「ドキュメント」内のフォルダを利用できます。Program Filesなど書き込み制限が強い場所は避けてください。

EXEだけを別の場所へ移動しないでください。runtime、config、helpなど、同梱フォルダが必要です。

2. Windowsの警告

未署名の配布版では「WindowsによってPCが保護されました」などが表示される場合があります。配布元とファイル名を確認し、信頼できる配布元から受け取ったものだけを実行してください。確認できないファイルは実行しないでください。

3. 初回起動

  1. AI-Office-Viewer-Manager.exeをダブルクリックします。
  2. ManagerがBackendとFrontendの状態、Codex CLI、Global Hooks、Codex Adapter、Backend API、Session Restore、Live Events、JSONL Monitorを確認します。
  3. 「起動」を押します。Portable版ではBackendが内部処理とViewer画面の配信をまとめて開始します。状態が「稼働中」になるまで数秒待ちます。
  4. 「Codex連携を診断」を押します。Global Hooksに問題がある場合だけ「Global Hooksを修復」を使います。

Portableキットには初期設定が同梱されます。実行後の設定はconfig、履歴などはdata、ログはlogsへ保存されます。

4. Viewerを開いてCodexを使う

  1. Managerの「ブラウザで開く」または「専用画面で開く」を押します。
  2. VS CodeでCodexを開始し、通常どおり依頼します。
  3. ViewerにMain Agentが表示され、補助AIが起動するとSubagentが別キャラクターとして表示されます。

誰も表示されない時は、まずCodexで実際に操作を1回行い、Managerの「Live Events」と「JSONL Monitor」を確認してください。詳しくはViewerが更新されないを参照してください。

5. 更新とアンインストール

更新

  1. Managerで「停止」を押し、タスクトレイから「終了」します。
  2. 旧フォルダをバックアップします。
  3. 新しいZIPを別フォルダへ展開します。
  4. 必要に応じて旧フォルダのconfigとdataを引き継ぎます。ログも必要な場合だけlogsをコピーします。
同じポートを使うため、古い版と新しい版を同時に起動しないでください。

アンインストール

  1. 「停止」でサービスを止め、タスクトレイの「終了」でManagerを終了します。
  2. Global Hooksを設定した場合は、配布フォルダでruntime\codex-adapter\uninstall-global-hooks.ps1を実行して連携を解除します。
  3. 必要な履歴をバックアップ後、Portableフォルダを削除します。
